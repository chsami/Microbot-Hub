# Inferno Prayers

Switches your protection and offensive prayers in the Inferno. You play everything else: movement, attacks, gear,
potions and inventory. Prayers are sent directly, without opening the prayer book or moving the mouse.

## Starting

Enable the plugin and enter the Inferno. It starts praying once you are inside, whether you enabled it before
logging in, before entering, or in the middle of a wave.

It stays ready between runs. After a death, a cape, leaving, or a lost connection it starts again by itself the next
time you are inside. If the client falls behind for a moment it carries on from the current tick. If it ever cannot
continue, it says so in game chat: pray manually, then turn the plugin off and on.

## Input yielding

While the plugin is enabled it keeps Microbot's "Disable input yielding" behaviour on, so prayer switches are not held
back while you click. This is applied in memory only. Your saved setting is not changed and is back in effect when you
turn the plugin off.

## Settings

- Show Inferno tile pack (on by default)
- Log out after death or cape

## Requirements

Microbot client 2.6.55 or newer.
