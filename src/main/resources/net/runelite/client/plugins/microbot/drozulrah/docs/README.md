# Dro Zulrah

Dro Zulrah automates Zulrah trips in Microbot. It supports fight rotations, prayer changes, gear and inventory switches, special attacks, thralls, and re-gearing between attempts.

## Usage

1. Install and enable **[Dro] Zulrah** in Microbot.
2. Configure the plugin for your inventory setup, equipment, supplies, and preferred combat options.
3. Start the script when you are ready to travel to Zul-Andra and begin a Zulrah trip.
4. Monitor the plugin overlay and status messages while it handles the trip.

## Notes

- The plugin requires Microbot client version **2.1.32** or later.
- Review your configured gear, inventory, supplies, and travel options before starting.
- Stop the script from the plugin controls when you want to end the trip.
