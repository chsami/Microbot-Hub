# Auto Gauntlet

By **Syd** (& claude ain't no way i was putting this together myself).

Plays the Normal / Corrupted Gauntlet start to finish: preps (gathers, kills monsters and the three demi-bosses, crafts your choice of armour plus a perfected bow and staff, brews Egniol potions, cooks paddlefish), walks into the boss room and fights the Corrupted Hunllef, then loots the Reward Chest and goes again. Set "Boss fight" to OFF to have it hand over to you at the boss barrier instead.

I recommend you babysit this while it's running. Given the complicated nature of the gauntlet, things can sometimes go wrong. For the most part it should be alright on it's own though.
