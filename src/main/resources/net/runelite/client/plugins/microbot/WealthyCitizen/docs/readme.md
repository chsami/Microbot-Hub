# Wealthy Citizen

Pickpockets Wealthy Citizens during urchin distractions.

## Features
- Automatically detects the "urchin distraction" chat message
- Starts pickpocketing as soon as the distraction is active


## Requirements
- You must already be at the Wealthy Citizen location before starting the script — it does not walk there automatically

## Location
This script targets Wealthy Citizens in Civitas illa Fortis, Varlamore.
Due to the pillars near the bazaar causing pathing issues, it is recommended to pickpocket **south of the bazaar**, at urchin **Aurelia**.

## Known limitations
- Does not travel to the location itself; manual positioning required
- No configuration options or UI panel (by design, kept minimal)

## Room for Improvement
